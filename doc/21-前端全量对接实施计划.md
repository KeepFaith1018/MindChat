# 前端全量对接后端实施计划（基于 v1 接口）

## 1. 文档目标

本文档用于在现有代码基础上，完成“前端对接后端全部可用能力”的分阶段实施规划，覆盖：

1. 功能范围清单与当前状态评估
2. 分阶段实现步骤（可直接执行）
3. 每阶段验收标准与测试项
4. 性能与可用性优化路线
5. 风险、回滚与发布策略

---

## 2. 范围与约束

### 2.1 后端能力范围（BaseURL: `/v1`）

1. Auth：注册/登录/登出/刷新/当前用户/OAuth
2. Models：可用模型与能力矩阵
3. Conversations：创建、列表、详情、更新、删除
4. Chat：SSE 聊天、能力查询
5. Upload：文件上传
6. Share：分享创建、分享 JSON、分享页面

### 2.2 前端技术约束

1. Nuxt 4 + Pinia + Nuxt UI
2. Cookie 鉴权（`credentials: 'include'`）
3. 统一响应结构 + SSE 特殊处理
4. 以“先闭环，再增强”为实施策略

---

## 3. 当前状态盘点（以代码为准）

### 3.1 已完成

## 4. 目标架构（前端）

### 4.1 API 层

新增或补齐 API 模块：

1. `app/api/models.ts`
2. `app/api/share.ts`
3. `app/api/capabilities.ts`（或合并入 `chat.ts`）

统一原则：

1. 所有 JSON 请求走 `$api`
2. SSE 保持 `fetchEventSource`
3. 错误码统一映射（业务码 + HTTP 码）

### 4.2 Store 层

建议拆分职责：

1. `useAuthStore`：用户态与会话恢复
2. `useConversationStore`：会话列表/详情/当前会话
3. `useChatStore`：发送、SSE、能力开关状态
4. `useModelStore`（可选）：模型列表、默认模型、能力矩阵缓存

### 4.3 UI 层

1. 聊天输入区：模型选择 + 能力开关 + 附件
2. 消息区：`thinking/content/tool_result/error` 的分区渲染
3. 头部：分享按钮触发弹窗
4. 分享页：优先使用后端直出，前端补一个可选自渲染页

---

## 5. 分阶段实施计划

## 阶段 A：能力基线补齐（P0）

### A1. 模型与能力初始化

实现内容：

1. 接入 `GET /models/available`
2. 聊天页初始化拉取模型数据
3. 默认模型按后端返回回落
4. 模型切换后更新能力开关可用状态

交付物：

1. `app/api/models.ts`
2. `useModelStore` 或 `useChatStore` 新增模型能力状态字段
3. 输入区模型下拉改为后端动态数据

验收标准：

1. 模型列表不再硬编码
2. 切换模型时开关灰置与 tooltip 正常

---

### A2. 聊天能力开关对接

实现内容：

1. 请求 `GET /chat/capabilities`
2. 输入区增加三个开关：`webSearch/reasoning/fileQa`
3. 发送消息时将开关状态带入 `/chat` 请求
4. 按后端能力矩阵进行强约束（不支持则不可开）

交付物：

1. 输入区能力开关 UI
2. `sendMessage` payload 能力字段

验收标准：

1. 开关状态可见、可控、可禁用
2. 后端返回“不支持能力”时前端有明确提示

---

### A3. SSE 事件协议完善

实现内容：

1. 完整处理 `meta` 中的 `model/capabilities`
2. 新增 `tool_result` 事件分发与状态更新
3. 事件解析失败保护与降级展示

交付物：

1. `useChatStore` 增加 `toolResults` 或消息级工具结果字段
2. 消息区支持来源结果渲染

验收标准：

1. 开启联网搜索后可看到来源卡片
2. SSE 各事件状态流转完整无报错

---

## 阶段 B：分享与传播能力（P0）

### B1. 分享创建

实现内容：

1. 接入 `POST /share`
2. Header 分享按钮打开弹窗
3. 允许设置 `expireHours`（先固定值，后做选择器）
4. 返回 `shareUrl` 后支持一键复制

交付物：

1. `app/api/share.ts`
2. `components/share/ShareDialog.vue`
3. Header 分享按钮实际可用

验收标准：

1. 已登录用户可生成分享链接
2. 复制成功有 toast 提示

---

### B2. 分享访问

实现内容：

1. 默认跳后端 `GET /share/:linkId/page`
2. 增加前端可选页（后续开关）：
   - `GET /share/:linkId` 获取 JSON
   - 前端渲染只读消息列表

交付物：

1. 分享外链访问策略说明（后端直出优先）
2. 可选前端只读页路由（P1 可并入）

验收标准：

1. 未登录可访问分享链接
2. 过期/无效链接有合理提示页

## 阶段 D：错误与稳定性治理（P0）

## 7. 交互提示词与文案方案

## 7.1 关键提示文案

1. 未登录：`请先登录后再继续操作`
2. 会话不存在：`当前会话不存在，请新建会话或选择其他历史对话`
3. 配额不足：`当前账户配额不足，请稍后再试或联系管理员`
4. 能力不支持：`当前模型不支持该能力，请切换模型后重试`
5. 分享成功：`分享链接已生成并复制到剪贴板`

## 7.2 Tooltip 规则

1. 能力开关禁用时必须解释原因
2. 模型切换导致能力关闭时给一次性提示
3. 上传失败提示包含“类型/大小/网络”原因

---

## 8. 测试计划（对接清单映射）

### 8.1 功能回归

1. 登录 -> 创建会话 -> SSE 对话成功
2. 模型切换 + 能力开关 -> 服务端生效验证
3. 上传 -> `fileIds` 生效 -> 回答引用文件
4. 开启 webSearch -> 出现 `tool_result` 卡片
5. 分享创建 -> 未登录访问分享页

### 8.2 异常回归

1. 401 自动刷新 + 重试
2. 43001 会话不存在处理
3. SSE 中断重连与超时提示
4. 46001 配额不足文案正确
